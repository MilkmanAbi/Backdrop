Make your own

A widget is one .html file, or a .zip with an index.html and its images, fonts and scripts. HTML, CSS and JavaScript as usual: animations, GIFs, fetch, WebSockets, games, anything.
Size it with <meta name="widget-size" content="300x150">. Widgets run at 24 fps; ask for more with <meta name="widget-fps" content="60">.
Round corners with border-radius. For any other shape add data-shape="M… Z" (an SVG path) to an element with a background image. Empty space around your elements is see-through and click-through.
